# SpeakSure Client Preview

Open `index.html` in a browser to view the clickable prototype locally.

To send a public link to a client, upload this whole `speaksure-preview` folder to a static hosting service such as Netlify, Vercel, or GitHub Pages. No backend, database, WordPress, or build step is required for this preview.

Suggested public-link path:

1. Create a free Netlify account.
2. Choose "Add new site" and "Deploy manually".
3. Drag the `speaksure-preview` folder into Netlify.
4. Copy the generated public URL and send it to the client.

The prototype includes:

- Classroom dashboard
- Business English class page
- Trial booking screen
- English and Chinese helper copy
- Mobile responsive layout
